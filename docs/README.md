# gocql2 Documentation

This directory contains maintainer and integrator documentation for gocql2.

- [Usage Guide](./usage.md) shows how to parse, serialize, validate, and compile CQL2.
- [Public API Reference](./public-api-reference.md) describes the exported packages and the
  public abstract filter representation in `github.com/cwygoda/gocql2/api`.
- [Code and Repository Structure](./code-and-repo-structure.md) describes the repository layout,
  internal packages, dependencies, and common change paths.
